About: Data Types

របៀបប្រើប្រាស់ Data Types

1. Integer (ចំនួនគត់)

$age = 25;

2. Float / Double (លេខទសភាគ)

$price = 12.5;

3. String (អក្សរ)

$name = "Sokha";

4. Boolean (true/false)

$isLogin = true;

5. Array (អារេ)

$colors = array("Red", "Green", "Blue");

6. Object

class Car {
  public $color;
}

$myCar = new Car();
$myCar->color = "Red";
echo "myCar: " . $myCar->color;

7. NULL (អថេរដែលគ្មានតម្លៃ)

$data = null;

8. Resource (ប្រើសម្រាប់ភ្ជាប់ធនធានខាងក្រៅ...)

$conn = mysqli_connect("localhost", "root", "", "test");

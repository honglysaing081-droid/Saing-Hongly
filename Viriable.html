About: Variable

1. របៀបប្រកាស Variable

រាល់ Variable ក្នុង PHP ទាំងអស់ត្រូវតែចាប់ផ្ដើមដោយសញ្ញាដុល្លារ $ ជានិច្ច។EX:

<?php
  $name = "Saing Hongly"; // ប្រភេទអត្ថបទ (String)
  $age = 20;              // ប្រភេទលេខ (Integer)
  $gpa = 3.5;             // ប្រភេទលេខទសភាគ (Float)
?>

2. ច្បាប់ក្នុងការដាក់ឈ្មោះ: Variable

  • ១. ត្រូវចាប់ផ្ដើមដោយសញ្ញា $
  • ២. បន្ទាប់ពីសញ្ញា $ ត្រូវតែជា អក្សរ ឬសញ្ញា Underscore (_)។ មិនអាចចាប់ផ្ដើមដោយលេខឡើយ។ មិនត្រូវដកឃ្លាក្នុងឈ្មោះ Variable ទេ
  • ៣. ឈ្មោះ Variable ដែលមានអក្សរតូច និងធំ គឺខុសគ្នា។ ឧទាហរណ៍ $color និង $COLOR គឺជា Variable ពីរផ្សេងគ្នា។
